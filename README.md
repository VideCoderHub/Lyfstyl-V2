# Lyfstyl Landing (MVP)

React + Vite landing page for a **food + dance** social product.

## Pages

| Menu | Route |
|------|-------|
| Home | `/` |
| Discover | `/discover` |
| Recipes | `/recipes` |
| Moves | `/moves` |
| Community | `/community` |
| Challenges | `/challenges` |
| Log in | `/login` |
| Join Now | `/join` |

## Run

```bash
cd feastbeat
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).
